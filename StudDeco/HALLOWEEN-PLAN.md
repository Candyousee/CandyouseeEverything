# Stud Deco: HALLOWEEN (plan)

**The product:** **120 Halloween decorations** in the Stud style (blocky, studded, chunky), at a quality bar set by the owner's reference sheet (`reference/halloween_refs.jpg`, ~300 concepts). It's sold on the Creator Store like Stud Pets.

**Deadline:** Halloween is 31 October, and developers buy decorations in the first half of October. **Ship v1 by ~15 October** with every item that meets the bar, then update the same listing with the rest. Never ship a weak item to hit the count.

## 1. Style (from the reference sheet)

| Rule | What it means |
|---|---|
| **Built from Parts, studs on top** | Block, Ball, Cylinder and Wedge parts. Flat tops get Roblox's built-in **Studs** surface (no extra parts), as in Stud Pets. Selling point: **100% Parts, no meshes, no uploads, recolour anything** |
| **Chunky and toy-like** | thick shapes, slight lean or tilt for character, nothing thin or fiddly. Every item reads as one shape at a distance |
| **Palette (fixed)** | pumpkin orange `#E8741E` / dark orange `#B4501A`; witch purple `#6A3FA0` / deep purple `#3B2560`; toxic green `#7BE04A`; bone cream `#EFE3C8`; stone grey `#6E6A78` / dark stone `#3E3A46`; wood brown `#6B4426` / dark wood `#3F2816`; near-black `#1E1A24`; gold `#E8B84A`; moss green `#5E8A3A` |
| **Glow** | Neon parts for faces, flames, potions and crystals, **plus a real PointLight** (orange `#FF9A3C`, purple `#A060FF` or green `#7CFF5A`), so they light up the buyer's map. Lights default to small ranges (8-12 studs) for performance |
| **Bases** | most standing items sit on a small chunky base (stone, dirt, roots or wood), like the references. It grounds them and makes placement easy |
| **Scale** | sized for standard Roblox avatars: a gravestone reaches about the knee, a lamp post about 1.5× player height, an arch is walk-through |
| **Detail budget** | small props 5-25 parts, furniture 20-60, hero pieces (arches, stalls, fireplaces) up to ~120. No part smaller than 0.2 studs |

## 3. How it's built (the Stud Pets method)

1. **One data file per category** (`items/*.luau`): each item is a short list of parts (shape, size, position, rotation, colour, material, studs on or off) plus its lights and effects. Shared helpers build the common shapes: ribbed pumpkin, skull, flame, candle, chunky base, stone block.
2. **`lune run build/build.luau`** writes:
   - one `.rbxm` per item;
   - the full `StudDeco_Halloween.rbxm` (folders by category);
   - a demo place with everything laid out.
3. **Every model:**
   - anchored, with CanCollide off on decorative bits;
   - the pivot at the base centre, so it sits on the ground when dropped in;
   - named parts;
   - no scripts, except the optional flicker / fog helper, which is off unless enabled.
4. **QA (automatic):**
   - part count per item within budget;
   - no part under 0.2 studs;
   - nothing floating or sunk below the base;
   - no overlapping same-colour faces (z-fighting);
   - lights within range limits;
   - every item has a pivot and a category folder.
5. **Previews:** Blender renders of every item on the dark backdrop (like the reference sheet), contact sheets per category, and hero shots.
